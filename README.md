# Tienda — E-commerce

Proyecto web de la materia **Laboratorio de aplicaciones web cliente**.

## Stack

HTML5, CSS3 vanilla (sin frameworks), JavaScript ES6 con modulos, Fetch y localStorage.
API de productos: [fakestoreapi.com](https://fakestoreapi.com/)

## Como correrlo

Clonar el repositorio y abrir `index.html` con la extension **Live Server** de VS Code.

> Los modulos ES6 necesitan servirse por HTTP. Abrir el archivo con doble clic
> (`file://`) no funciona.

## Funcionalidades

- Listado de productos consumidos de la API
- Modal con el detalle de cada producto
- Carrito persistente en localStorage
- Badge con la cantidad total de unidades
- Sidebar con controles de cantidad, eliminar y subtotal por producto
- Finalizar compra y vaciar carrito
- Buscador de productos
- Navegacion por categorias
- Diseno responsive
